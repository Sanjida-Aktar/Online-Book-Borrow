# BookVerse - Library Management System

## Project Purpose

BookVerse is a modern and responsive digital library management web application that allows users to explore, search, and borrow books online. The platform provides a seamless reading experience with secure authentication and user profile management. Users can browse books by category, view book details, and update their personal information.

## Key Features

- Secure authentication system using Better Auth.
- User registration and login with email and password.
- Google social login support.
- Responsive design for mobile, tablet, and desktop.
- Browse all available books.
- Search books by title.
- Filter books by category (Story, Tech, Science).
- Featured books section on the homepage.
- Private book details page.
- Borrow book functionality.
- User profile page with personal information.
- Update profile name and profile image.
- Protected routes for authenticated users.
- Beautiful and modern UI using Tailwind CSS and DaisyUI.
- Interactive marquee section for announcements.
- Fully responsive navigation bar and footer.
